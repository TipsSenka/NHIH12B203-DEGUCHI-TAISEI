Pagesの画面からWorkersのAPIを呼び出し、返ってきたJSONを表示します。ボタンを押すと、下の図で通信がどこまで進んだか確認できます。

  1. Pages（フロントエンド）

    画面から要求

    fetch() で送信

  2. API

    APIが受け取る

    HTTP で通信

  3. Workers（バックエンド）

    Workersが処理

    Response を返す

  4. Pages（フロントエンド）

    画面へ表示

    JSON を表示
